# Proyecto_I+D_BD

## Descripción

Proyecto de investigación sobre bases de datos no relacionales (NoSQL). El trabajo presenta sus conceptos fundamentales, los principales modelos de almacenamiento y los escenarios en los que pueden ser útiles. También permite comparar sus características con las de las bases de datos relacionales.

## Objetivos

- Comprender qué son las bases de datos NoSQL y qué necesidades buscan atender.
- Identificar los modelos principales: clave-valor, documentos, familias de columnas y grafos.
- Analizar características como flexibilidad del esquema, escalabilidad, disponibilidad y consistencia.
- Reconocer ventajas, limitaciones y criterios de selección según los requisitos de cada aplicación.

## Alcance

El proyecto tiene un enfoque de investigación. No se especifica aquí una base de datos, aplicación o implementación concreta; las herramientas, pruebas y resultados se documentarán cuando se definan como parte del trabajo.

## Organización sugerida

1. Introducción a las bases de datos no relacionales.
2. Descripción y comparación de sus modelos de datos.
3. Diferencias generales frente al modelo relacional.
4. Ventajas, limitaciones y casos de uso.
5. Conclusiones de la investigación.
